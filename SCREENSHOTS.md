# Screenshots

Before/after comparison of Blackout on a live page (Wikipedia's "Dark mode"
article), same layout used by Dark Reader and similar extensions: one plain
"before" shot, one "after" shot with the extension's own popup panel open so
the toggle/slider controls are visible.

- `screenshots/before.png` — page in its normal light theme, extension off.
- `screenshots/after.png` — same page darkened by Blackout, popup open
  showing Enabled toggle, per-site override, brightness/contrast/sepia/
  grayscale sliders, and the auto dark-by-time-of-day schedule.
- `screenshots/before-after.png` — both combined side by side, used on the
  landing page and as the first Firefox AMO listing screenshot.
