Install Blackout

Where's the Chrome/Edge/Firefox store listing?
Not submitted yet — store review takes a few days per browser. Until each listing is live, you can install directly from the zip below in about a minute using your browser's built-in "load unpacked extension" developer option. It's the exact same code that will ship on the stores.

Chrome / Edge

  1. Download: blackout-chrome-v1.0.0.zip
  2. Unzip it — you'll get a folder with manifest.json inside.
  3. Open chrome://extensions (Edge: edge://extensions).
  4. Turn on Developer mode (top right toggle).
  5. Click Load unpacked and select the unzipped folder.
  6. Done — the icon appears in your toolbar. Click it to toggle dark mode.

Firefox

  1. Download: blackout-firefox-v1.0.0.zip
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on… and select the manifest.json file from inside the unzipped folder (no need to unzip fully — Firefox can also load the zip directly here in some versions).
  4. Done. Note: temporary add-ons in Firefox are removed when you close the browser — this is normal for pre-store testing. The permanent version arrives once the AMO listing is approved.

Safari

Safari requires converting and signing the extension on macOS with Xcode before it can be installed at all — there is no zip/unpacked option on Safari. This is in progress; check back or ask directly for a status update.
